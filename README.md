# Geely Monjaro — База знаний

Статическая вики без сборки. GitHub Pages публикуется из `main:/docs`.

- `docs/` — интерфейс и локальные библиотеки Markdown.
- `md/` — содержимое страниц и иллюстрации.
- `docs/app.js` — маршруты страниц и дерево меню (`pages`, `treeData`).

## Редактирование

Содержимое страницы хранится в отдельном `.md`. Первый H1 используется как название в исходнике и не дублируется при отображении: заголовок интерфейса задаётся в `pages`.

Чтобы добавить страницу, создайте Markdown-файл в `md/`, добавьте маршрут в `pages` и пункт в `treeData`. Иерархия и порядок меню задаются явно.

На опубликованном сайте Markdown загружается из публичной ветки `main` через `raw.githubusercontent.com`. Дата страницы — дата последнего коммита её файла через GitHub API; дата в футере — последний push репозитория. При недоступности API показывается «недоступна». Даты отображаются по Москве.

## Локальный просмотр

```sh
python3 scripts/preview.py
```

Откройте http://127.0.0.1:8765/. Сервер отдаёт интерфейс из `docs`, а `/md/` — из `md`. Локальная дата страницы берётся из времени изменения файла. Зависимости устанавливать и сборку запускать не нужно.

## Форматирование

Примеры: `md/markdown-demo.md`. Поддерживаются GFM, сноски, уведомления GitHub и безопасный HTML. Mermaid, формулы, GeoJSON/STL и специфические ссылки GitHub пока не преобразуются в виджеты. Сведения о сторонних библиотеках и лицензиях — в `docs/vendor/`.
